# Requirements

## Audio Input
- 3.5mm Input
- Integrated Microphone

## Audio Output
- 3.5mm Output
- Integrated Speaker

## User Interface
- Record Button
- Stop Button
- Play Button
- Output Volume Dial
- Record light
- Fast Forward button
- Rewind Button
- Display to show recorder status

## Power
- Battery

## Storage
- SD card storage

## Audio Codec
- 24 (32?) bit float recording
