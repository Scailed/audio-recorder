# Requirements

## Audio Input
- 3.5mm TRRS Input
- Integrated Microphone

## Audio Output
- 3.5mm Output
- Integrated Speaker

## User Interface
- Record Button
- Stop Button
- Play Button
- Record light
- Fast Forward button
- Rewind Button
- Output Volume Buttons
- Display to show recorder status
- LED VU Meters
- One-tap memo button
- 2 User-Defined buttons
- Power switch

## Power
- Battery
    - LiPo battery, 1700 - 2000 mAh capacity
- USB-C Charging
    - Around 0.96 A of charging

## Storage
- SD card storage

## Audio Codec
- 24 (32?) bit float recording

## MCU
- I2S or TDM Peripheral
- I2C or SPI Interface
- Audio clock
- SDIO

## USB
- USB High-speed transfer over USB-C
